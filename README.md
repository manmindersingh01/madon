# Madon 🛍️

Madon is a minimalist ecommerce platform for my personal clothing brand. It currently handles 3000–5000 visitors monthly and demonstrates design and branding expertise.

## 🌐 Live
[https://madon.vercel.app/](https://madon.vercel.app/)

## 🛠️ Tech Stack
- Next.js
- TailwindCSS
- Design Tools (Figma, Adobe)

## ✨ Features
- Custom-branded ecommerce store
- Optimized for traffic and conversions
- Responsive UI with color theory principles
